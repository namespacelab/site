FAQ accordion

Questions, natively

details/summary with an optional Open all toggle and an optional FAQPage schema block.

Does this work without JavaScript?

Yes. The accordion is native HTML. JavaScript only adds the Open all button.

Can only one answer be open at a time?

Yes, set exclusive to true. Browsers group the items natively.

When should the schema option be used?

Only on indexable pages, and only for questions shown on that page.
